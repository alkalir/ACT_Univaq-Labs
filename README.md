# ACT Univaq Labs

This repository collects hands-on lab material for the Advanced Computing Technologies course. The labs are designed to be self-contained: each one focuses on a specific area of modern computing architecture and can be followed independently.

## Available labs

- **MIMD** — Hands-on introduction to multi-threaded programming using OpenMP. You will write parallel programs, measure speedup, and understand the pitfalls of shared-memory parallelism. *Available now.*

- **BasicCPUConcepts** — Labs on how to study and profile a modern processor: using performance counters, understanding instruction-level parallelism, branch prediction, and SIMD. *Work in progress — coming soon.*

- **GPU** — Labs on GPU architecture and programming: understanding GPU performance characteristics and writing programs that exploit massive parallelism. *Work in progress — coming soon.*

- **HDLLanguages** — Tutorials on Hardware Description Languages, the formal way to describe a computing architecture. A bridge between hardware and software: useful for anyone who wants to understand how a processor is actually specified and built. *Work in progress — coming soon.*

## Follow along

New labs will be released progressively over the coming months. If you are interested, star this repository to stay updated.
