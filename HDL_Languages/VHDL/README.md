# VHDL

This folder is about **VHDL**, a hardware description language used to model and design digital circuits.

## Where to start

If you are new to VHDL, a great place to learn it is the tutorial repository of the **Embedded Systems** course at Univaq:

👉 **[EmbeddedSystemsUnivaq_VHDL](https://github.com/alkalir/EmbeddedSystemsUnivaq_VHDL)**

It is a step-by-step resource you can follow on your own.
